# Cycle 3 — UX polish — verification report (2026-06-25)

Branch `autopilot/cycle3-ux-polish`. Design:
`docs/superpowers/specs/2026-06-25-ux-polish-design.md`. App-layer only — the ChromaDB collection,
BM25 index, and corpus/embeddings were **not** touched (no re-embed, no re-tag).

## What shipped

1. **Relevance-scored, size-tiered source bubbles (SP1).** The cross-encoder reranker computed a
   per-chunk relevance score and discarded it; it now rides each chunk on `_score`. `_dedupe_sources`
   derives a per-source `relevance` (0–1, min-max normalized across the answer's source set) and a size
   `tier` (high ≥ 0.66 / med ≥ 0.33 / low), with a rank-position fallback when the reranker is off. The
   frontend sizes each bubble by tier (top source = first + biggest, accent border-top) and packs them
   in a 2-column masonry (`columns: 2 232px`) so differently-sized bubbles fill space without gaps. No
   inline `[n]` citation tagging (explicitly cut) — the grounded answer prose is unchanged.
2. **Original cosmic SVG backdrop (SP2).** The all-games "Xeno Series" view's flat CSS gradient +
   starfield is replaced by a hand-authored full-bleed `<svg class="cosmic">`: gold/turquoise/violet
   nebula, a distant shaded planet, a faint large Zohar monolith (the brand motif at scale) with a
   turquoise core glow, and 48 parallax stars (6 gently twinkle; `prefers-reduced-motion` honored).
   Bottom-masked + low alphas keep prose legible. Per-game key-art washes are untouched.
3. **Answer-style depth + Faster/Thinking copy (SP3).** "Faster" (flash-lite) trimmed from
   `top_k 20 / cap 5` to **`14 / 4`**; "Thinking" (flash-3.5) stays `40 / 6` with wider candidate pools.
   Selector labels + a dynamic helper now state that Faster suffices for most questions and Thinking
   reads more of the wiki at once for complex, multi-topic ones.
